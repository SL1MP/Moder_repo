# Корпоративные CA для исходящего OIDC

Положите сюда публичные сертификаты корневого и промежуточного корпоративного
центра сертификации в PEM-формате (`*.crt`, `*.cer` или `*.pem`). Закрытые
ключи здесь не нужны и не должны храниться.

Docker Compose монтирует каталог read-only в `/etc/moderation/ca`. Файлы
сертификатов исключены из Git; в репозитории остаётся только эта инструкция.
