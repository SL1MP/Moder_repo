# Дизайн — единый с sentrix/oakshield

Источник — `sentrix`'s `.claude/Design_patterns.md` (сам он ссылается на официальный
`PT_Brand_Guidlines_v.02.pdf`, "Цветовая палитра", стр. 17 — только пять цветов бренда:
white/frost/sky/red/black, всё остальное — собственное расширение проекта, не регламентировано
брендбуком).

## Что сделано

Фронтенд (`frontend/src/styles.css`) уже был полностью на CSS-переменных
(`:root { --bg; --accent; --pass; ... }`) — по классификации самого sentrix (см. его
"Импорт нового сервиса в этот стиль", п.2) это "повезло": палитра заменена только в токенах,
без переборки разметки:

- `--bg`/`--bg-elev`/`--bg-elev-2` → `#212121`/`#2c2c2c`/`#363636` (тёмный "paper"/"surface" по
  дневному конвертированию sentrix из официального бренд-чёрного).
- `--text`/`--text-dim`/`--text-faint` → белый + rgba-полупрозрачности (ink/ink-soft/ink-faint,
  тёмный вариант).
- `--accent` → `#ff3b3b` (фирменный red, тёмный вариант) — раньше был синий `#4c8dff`, ничем не
  обоснованный брендбуком.
- `--pass`/`--warn`/`--fail` → `#3ecf8e`/`#e3ac48`/`#ff3b3b` — цвета статусов sentrix
  (green/amber/red), тёмные варианты.
- `--radius` → `3px` (правило sentrix "радиус 3px везде", было `6px`).
- Шрифт — `'TT Positive'` добавлен первым в стек (фирменный шрифт брендбука; файлы шрифта не
  поставляются — коммерческая лицензия, как и в sentrix — честный fallback на системный sans,
  если не установлен локально).
- Точечно поправлен один захардкоженный цвет, привязанный к старому синему акценту:
  `button.primary:hover` (`#3d7ae8` → `#e63333`, тёмный hover для нового красного).

## Что осознанно не сделано (не путать с "не нужно")

Это только цветовой слой ("перекраска", по терминологии sentrix), не паттерны компонентов:

- Бейджи статусов (`.badge.pass`/`.badge.warn`/...) сохранили собственные тёмные оттенки
  (`#10281a`/`#2b2312`/`#2c1618` и т.д.) — они и раньше были в правильных цветовых семьях
  (зелёный/жёлтый/красный), трогать не потребовалось для соответствия семантике.
- **Не перенесён** паттерн sentrix "статус = точка + mono uppercase текст" и "бейдж = mono
  uppercase на 10%-tint фоне" — сейчас бейджи не mono и не uppercase. Это отдельная,
  более крупная задача (меняет вёрстку/типографику компонентов, не только цвета) — если нужна
  визуальная идентичность вплоть до этого уровня, стоит обсуждать отдельно, не молча
  дотягивать по ходу.
- Не проверено визуально — не поднимался `npm run dev`/полный docker-compose стек (Keycloak/
  Nexus и т.д. — тяжёлый стек для быстрой проверки одной перекраски). Значения посчитаны по
  формулам sentrix, но **не просмотрены в браузере** — стоит открыть UI перед тем, как считать
  задачу завершённой.

## Компонентные паттерны sentrix — на заметку для следующей итерации

Из `.claude/Design_patterns.md`: карточка — белая/тёмная поверхность с рамкой 1px, у "основной"
карточки — верхняя рамка 3px red (не левая); кнопка primary — залита red, outline — 1.5px
прозрачная; таблица — шапка на paper-фоне, нижняя рамка шапки 1.5px line-strong; никаких
градиентов/эмодзи/декоративных теней кроме одной внешней `0 12px 40px rgba(0,0,0,.08)`.
